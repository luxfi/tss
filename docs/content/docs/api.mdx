# API Reference

## Core Types

### tss.Parameters
Configuration parameters for TSS protocols.

```go
type Parameters struct {
    // Elliptic curve (S256 for ECDSA, Edwards for EdDSA)
    EC() elliptic.Curve

    // Party context containing all participants
    Parties() *PeerContext

    // This party's identifier
    PartyID() *PartyID

    // Total number of parties
    PartyCount() int

    // Threshold value (t in (t,n)-threshold)
    Threshold() int

    // Random source for protocol operations
    Rand() io.Reader

    // Random source for partial key generation
    PartialKeyRand() io.Reader
}
```

### tss.PartyID
Unique identifier for a party in the protocol.

```go
type PartyID struct {
    // Unique identifier string
    Id string

    // Human-readable name (optional)
    Moniker string

    // Cryptographic key for party identification
    Key *big.Int

    // Index in the sorted party list
    Index int
}

// Constructor
func NewPartyID(id, moniker string, key *big.Int) *PartyID
```

### tss.PeerContext
Manages the set of parties participating in a protocol.

```go
type PeerContext struct {
    // Get all party IDs
    IDs() SortedPartyIDs

    // Set IDs excluding a specific party
    IDsExcluding(exclude *PartyID) SortedPartyIDs
}

// Constructor
func NewPeerContext(parties SortedPartyIDs) *PeerContext
```

### tss.Message
Protocol message exchanged between parties.

```go
type Message interface {
    // Get all recipient party IDs
    GetTo() []*PartyID

    // Get sender party ID
    GetFrom() *PartyID

    // Check if broadcast message
    IsBroadcast() bool

    // Check if message is for a specific party
    IsToOldCommittee() bool

    // Get message routing information
    GetRouting() MessageRouting

    // Validate message structure
    ValidateBasic() bool

    // Get message type string
    Type() string

    // Serialize message to bytes
    Bytes() ([]byte, error)
}
```

## Key Generation API

### keygen.LocalParty
Local party implementation for distributed key generation.

```go
type LocalParty struct {
    tss.BaseParty
    // Internal state
}

// Create new key generation party
func NewLocalParty(
    params *tss.Parameters,
    out chan<- tss.Message,
    end chan<- *LocalPartySaveData,
    preParams *PreParams, // Optional, can be nil
) tss.Party

// Start the key generation protocol
func (p *LocalParty) Start() *tss.Error

// Process incoming message
func (p *LocalParty) UpdateFromBytes(
    wireBytes []byte,
    from *tss.PartyID,
    isBroadcast bool,
) (ok bool, err *tss.Error)

// Handle protocol errors
func (p *LocalParty) ValidateMessage(msg tss.Message) *tss.Error
```

### keygen.LocalPartySaveData
Persistent data from key generation that must be stored securely.

```go
type LocalPartySaveData struct {
    // This party's key share
    Xi *big.Int

    // Shamir shares from all parties
    Ks []*big.Int

    // BigXj[j] = Xj = gˣʲ
    BigXj []*crypto.ECPoint

    // Paillier key for MTA protocol
    PaillierSK *paillier.PrivateKey

    // Paillier public keys from all parties
    PaillierPKs []*paillier.PublicKey

    // Pre-computed safe primes
    NTilde, H1, H2 *big.Int

    // Threshold value
    Threshold int

    // Party information
    PartyID *tss.PartyID
}

// Get the public key
func (data *LocalPartySaveData) ECDSAPub() *crypto.ECPoint
```

### keygen.PreParams
Pre-computed parameters for faster key generation.

```go
type PreParams struct {

// Generate pre-parameters with timeout
func GeneratePreParams(
    timeout time.Duration,

```

## Protocol Flow Control

### tss.Party
Base interface for all protocol parties.

```go
type Party interface {
    // Start the protocol
    Start() *Error

    // Process incoming message bytes
    UpdateFromBytes(
        wireBytes []byte,
        from *PartyID,
        isBroadcast bool,
    ) (ok bool, err *Error)

    // Get party ID
    PartyID() *PartyID

    // Get current round number
    Round() Round

    // Check if protocol completed
    WaitingFor() []*PartyID
}
```

### tss.Round

```go
type Round interface {

    // Check if round can proceed
    CanProceed() bool

    // Process received messages

    // Move to next round

    // Check if final round
    IsFinal() bool
}
```

## Example: Complete Key Generation

```go
package main

import (
    "fmt"
    "sync"
    "time"

    "github.com/luxfi/tss/v2"
    "github.com/luxfi/tss/v2/ecdsa/keygen"
)

func runKeygen(threshold, parties int) {
    // Setup
    var wg sync.WaitGroup
    outChs := make([]chan tss.Message, parties)
    endChs := make([]chan *keygen.LocalPartySaveData, parties)

    // Create party IDs
    partyIDs := make([]*tss.PartyID, parties)
    for i := 0; i < parties; i++ {
        id := fmt.Sprintf("party-%d", i)
        key := tss.GeneratePartyKey(id)
        partyIDs[i] = tss.NewPartyID(id, id, key)
    }
    sortedIDs := tss.SortPartyIDs(partyIDs)

    // Pre-generate parameters for speed
    preParams, _ := keygen.GeneratePreParams(1 * time.Minute)

    // Start parties
    for i := 0; i < parties; i++ {
        wg.Add(1)
        go func(index int) {
            defer wg.Done()

            // Setup channels
            outChs[index] = make(chan tss.Message, parties*10)
            endChs[index] = make(chan *keygen.LocalPartySaveData, 1)

            // Create parameters
            ctx := tss.NewPeerContext(sortedIDs)
            params := tss.NewParameters(
                tss.S256(),
                ctx,
                partyIDs[index],
                parties,
                threshold,
            )

            // Create and start party
            party := keygen.NewLocalParty(
                params,
                outChs[index],
                endChs[index],
                preParams,
            )

            go party.Start()

            // Handle message routing
            for msg := range outChs[index] {
                // Route to recipients
                go routeMessage(msg, partyIDs, outChs)
            }
        }(i)
    }

    wg.Wait()
    fmt.Println("Key generation completed!")
}
```
